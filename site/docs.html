API docs

Base URL (self-hosted): https://your-host · All responses are JSON. Every route also exists as a static file under /api-static/v1/… — host the folder on GitHub Pages or Cloudflare Pages and you have a free, serverless API.

Endpoints

RouteReturns
GET /v1/exercisesAll exercises. Query: limit (default 25, max 500), offset, search
GET /v1/exercises/:idOne exercise by id
GET /v1/exercises/bodyPart/:bodyPartExercises for a body part (paginated)
GET /v1/exercises/target/:targetExercises by target muscle (paginated)
GET /v1/exercises/equipment/:equipmentExercises by equipment (paginated)
GET /v1/bodyPartListAll body parts
GET /v1/targetListAll target muscles
GET /v1/equipmentListAll equipment values
